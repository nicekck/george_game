# Stop 10.00 ⏱️ — 10초 가챠 게임

모바일 브라우저에서 바로 즐기는 **10초 맞추기 게임**입니다.
가챠샵 컨셉: 투명한 부스 안 의자 위에 커다란 인형 3개가 있고,
동전을 넣고 START를 누르면 음성으로 **"삼·이·일"**을 외친 뒤 스톱워치가 작동합니다.
정확히 **10.00초**에 멈추면 부스의 문이 열리고 인형을 획득합니다!

## 플레이 방법
1. **🪙 동전 넣고 START** 버튼을 누릅니다.
2. 음성 카운트 **"삼 → 이 → 일 → GO!"** 후 스톱워치가 작동합니다.
   - 스톱워치에 **시간이 실시간으로 표시**됩니다(예 `02.34`).
3. 정확히 **10.00초**가 되는 순간 커다란 빨간 **STOP** 버튼(또는 화면 아무 곳)을 탭!
4. 판정 결과:
   | 결과 | 조건 |
   |------|------|
   | 🎉 **JACKPOT** (문 열림) | 정확히 `10.00` |
   | 😖 아쉽다! 거의! | 오차 ±0.03초 이내 |
   | 🙂 가까워요 | 오차 ±0.10초 이내 |
   | ❌ 실패 | 그 외 (▲빨랐어요 / ▼늦었어요 힌트) |

   최고 기록(10.00에 가장 근접한 오차)과 잭팟 횟수는 자동 저장됩니다.

- 키보드: `Space` / `Enter` = START·STOP·다시 시작

## 실행
설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.

로컬 서버로 실행하려면(모바일 실기기 테스트 권장):
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 스톱워치 가챠 게임 전체 (HTML + CSS + JS, 런타임 의존성 없음) |
| `jump.html` | 이전 게임 **George Jump**(원탭 무한 점프) — 그대로 보존 |
| `manifest.json`, `sw.js` | PWA(홈 화면 설치 · 오프라인 캐시) |
| `assets/` | 아이콘 · George Jump 스프라이트 |
| `tools/pixelize.py` | 사진 → 픽셀 아트 변환 스크립트 (George Jump 개발용) |

> 이전 점프 게임을 즐기려면 시작 화면 우측 하단의 **🏃 George Jump →** 링크 또는 [`jump.html`](jump.html)로 이동하세요.

## 기술
- 순수 HTML5 Canvas 2D, 외부 라이브러리 없음
- 반응형 캔버스(논리 좌표 + 화면 비율 스케일), DPR/노치 대응
- 시간 측정은 `performance.now()` 기반(정밀), 카운트다운은 Web Speech(TTS `ko-KR`) + Web Audio 비프 폴백
- 터치 스크롤·줌 방지, `requestAnimationFrame` 게임 루프, PWA 오프라인 지원
